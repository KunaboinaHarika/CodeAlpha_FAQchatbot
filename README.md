# Smart FAQ Assistant Chatbot 🤖

An NLP-powered interactive chatbot designed to process user inquiries and automatically deliver accurate answers regarding the CodeAlpha Artificial Intelligence Internship using Natural Language Processing (NLP) techniques[span_1](start_span)[span_1](end_span).

## 🚀 Key Features
- **NLP Text Preprocessing**: Tokenizes, cleans, and removes stopwords using NLTK for better query understanding[span_2](start_span)[span_2](end_span).
- **Cosine Similarity Matching**: Converts questions using TF-IDF vectorization and matches user intent based on cosine similarity[span_3](start_span)[span_3](end_span).
- **Interactive Chat Interface**: Modern, conversational Streamlit chat UI for seamless interaction[span_4](start_span)[span_4](end_span).
- **Confidence Fallback**: Handles out-of-scope or ambiguous questions with a helpful default response[span_5](start_span)[span_5](end_span).
